HELPTECH - MATERIAL DO ALUNO
============================

Este pacote contém os arquivos-base para a avaliação prática de Desenvolvimento e Implantação de Sistemas.

O estudante deverá realizar a implantação, configuração, testes, diagnóstico e documentação conforme as orientações fornecidas pelo professor.

REQUISITOS
- Apache
- PHP
- MySQL/MariaDB
- Navegador web

ESTRUTURA
sistema/ -> aplicação web
banco/   -> script do banco de dados

Após a implantação, utilize as credenciais fornecidas pelo avaliador.
